# Outlook — Human Weather & Daily Activity Forecast

> **Core Philosophy:** Most weather apps only display numbers. **Outlook** answers the question that actually matters: *"What should I do with today's weather?"*

Built with React (Vite) and plain CSS. Powered by [Open-Meteo](https://open-meteo.com/) (free meteorological data, no API key required).

---

## Highlights & Features

1. **Editorial Asymmetric Layout**:
   - Replaces the generic grid of rounded cards with an editorial, magazine-style layout featuring a giant temperature figure in `Fraunces` serif paired with `Albert Sans` for details.
   - Varied spacing and high contrast for effortless readability.

2. **Plain-Language Daily Verdict**:
   - A human-written summary generated by an algorithmic rules engine (`src/utils/summary.js`) evaluating temperature, feels-like discrepancy, humidity, rain chance, wind speed, and UV index.
   - Answers: *What should I wear? Should I carry an umbrella? What is the outdoor vibe throughout the day?*

3. **Dynamic Rain Countdown**:
   - Tells you precisely when precipitation arrives: *"Rain starts in ~42 minutes"* or *"Rain expected around 4:00 PM"* or *"No rain expected today. Clear skies ahead."*

4. **Best Time to Go Out (Activity Planner)**:
   - A 24-hour horizontal comfort timeline scoring every hour (Prime, Pleasant, Fair, or Harsh) based on apparent temperature, precipitation risk, wind, and midday UV.
   - Automatically computes and highlights today's prime walking/outdoor window.
   - Interactive scrub and click to inspect any hour's exact conditions.

5. **Real-Sun Sky Theme Engine**:
   - Calculates the city's exact sunrise and sunset times to transition the background palette naturally across 5 distinct phases:
     - **Dawn Mist**: Warm sandstone, morning blush, soft earth tones.
     - **Natural Daylight**: Crisp limestone, mineral linen, calm moss accents.
     - **Golden Hour**: Amber honey, toasted terracotta, bronze glow.
     - **Twilight Dusk**: Warm charcoal, dusky copper slate.
     - **Starry Obsidian**: Deep espresso ink and warm starry slate (no cyber purple or neon blues).

6. **City Search with Geocoding Autocomplete**:
   - Debounced search leveraging Open-Meteo's geocoding API with full keyboard navigation (Up, Down, Enter, Escape).
   - Instant "Near Me" GPS button with polite permission fallback and client reverse geocoding.
   - Recent cities saved in `localStorage` for 1-click access.

7. **Units & Accessibility**:
   - °C / °F toggle persisted across sessions.
   - Semantic HTML5, ARIA labels, focus rings, and high contrast.
   - Shimmering loading skeletons and friendly error states.

## Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Vanilla CSS with CSS custom properties (`src/styles/variables.css` & `src/styles/global.css`)
- **Typography:** Google Fonts (`Fraunces` variable serif + `Albert Sans`)
- **Weather Data:** Open-Meteo Weather Forecast API & Geocoding API
- **Icons:** Custom consistent inline SVG line art

## Local Setup

### Prerequisites
- Node.js (version 18 or newer)
- npm (version 9 or newer)

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:5173/`.

### 3. Production Build
```bash
npm run build
```
The optimized bundle will be created in the `dist/` directory.

---

## Deployment

### Vercel
1. Push the code to a GitHub repository or use the Vercel CLI:
   ```bash
   npx vercel
   ```
2. Set the build command to `npm run build` and output directory to `dist`.

### GitHub Pages
1. In `vite.config.js`, set `base: './'` for relative asset paths:
   ```js
   export default defineConfig({
     base: './',
     plugins: [react()]
   })
   ```
2. Run `npm run build` and publish the `dist` folder to your `gh-pages` branch.
